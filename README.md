# Student Result Management System

## Overview

Student Result Management System is a Java-based console application designed to manage student information and academic results.

## Features

* Add student
* View student records
* Search student
* Enter subject marks
* Calculate total marks
* Calculate percentage
* Calculate grade
* Generate result report
* Save result to a text file
* Input validation
* Exception handling

## Technologies Used

* Java
* ArrayList
* File Handling
* Exception Handling
* Git and GitHub

## How to Run

1. Download or clone this repository.
2. Open the project in a Java-supported IDE.
3. Compile the Java files.
4. Run `Main.java`.
5. Select an option from the menu.

## Testing

The system was tested using valid and invalid student details, marks validation, student searching, result calculation and file saving.
