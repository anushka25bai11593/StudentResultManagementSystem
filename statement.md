# Project Statement

## Problem Statement

Manual management of student records and result calculations can be time-consuming and may cause calculation errors.

## Scope

The project focuses on managing student details, marks and academic results using a Java console application.

## Target Users

* Students
* Faculty members
* Academic administrators

## High-Level Features

* Student registration
* Student record viewing
* Student searching
* Marks entry
* Result calculation
* Grade generation
* Result report generation
* File-based result storage
* Input validation and error handling
